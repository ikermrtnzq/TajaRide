# TajaRide
## Descripción

TajaMove es una plataforma web que busca conectar a las personas de Tajamar a través de eventos, grupos y movilidad compartida.

La idea es que cualquier alumno de tajamar pueda consultar los eventos que se organizan en Tajamar, independientemente del curso o máster al que pertenezca, apuntarse y conocer a otros asistentes. También podrá crear grupos o unirse a otros para acudir juntos a los eventos.

Además, la plataforma permitirá organizar desplazamientos compartidos en coche, de manera que los usuarios puedan ofrecer plazas si tienen vehículo o buscar transporte si lo necesitan.

## Objetivos del proyecto

- Reunir en un mismo sitio todos los eventos de Tajamar.
- Facilitar que cualquier persona pueda participar en los eventos.
- Permitir crear grupos y unirse a ellos para asistir juntos.
- Mostrar cuántas personas van a cada evento.
- Facilitar la organización de viajes compartidos.
- Ayudar a los usuarios a encontrar transporte y compartir gastos.

## Funcionalidades principales

### Eventos
- Calendario con los próximos eventos de Tajamar.
- Información de cada evento.
- Posibilidad de apuntarse a cualquier evento.
- Consulta del número de asistentes.

### Grupos
- Crear grupos dentro de un evento.
- Unirse a grupos ya creados.
- Consultar quién forma parte de cada grupo.
- Organizarse para asistir juntos.

### Viajes compartidos
- Publicar viajes si se dispone de coche.
- Buscar viajes si se necesita transporte.
- Indicar el número de plazas disponibles.
- Organizar viajes de ida, vuelta o ida y vuelta.
- Reservar plazas en los vehículos.

### Cola de espera
- Apuntarse a una lista de espera cuando un viaje esté completo.
- Acceder a una plaza si otro usuario cancela su reserva.

### Trayectos recurrentes
- Publicar desplazamientos habituales.
- Organizar horarios de ida y vuelta.
- Compartir coche para los desplazamientos diarios.
